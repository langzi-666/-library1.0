# 测试数据使用说明

## 文件说明

- `init.sql` - 数据库初始化脚本，包含表结构创建和基础数据
- `test_data.sql` - 测试数据脚本，包含丰富的测试数据供开发和测试使用

## 使用方法

### 1. 初始化数据库

首先执行初始化脚本创建数据库和表结构：

```bash
mysql -u root -p < database/init.sql
```

或者使用MySQL客户端工具执行 `database/init.sql` 文件。

### 2. 导入测试数据

执行测试数据脚本：

```bash
mysql -u root -p < database/test_data.sql
```

或者使用MySQL客户端工具执行 `database/test_data.sql` 文件。

## 常见问题

### Q: 执行测试数据脚本时出现外键约束错误？
A: 确保先执行了 `init.sql` 创建表结构和基础数据。

### Q: 分类ID引用错误？
A: 检查 `init.sql` 中的分类顺序，确保测试数据中的分类ID正确引用。

### Q: 密码无法登录？
A: 检查密码存储方式，确保与代码实现一致（明文或MD5）。

### Q: 借阅记录状态不正确？
A: 检查借阅记录的日期设置，确保逻辑正确（借阅日期 < 应还日期，逾期记录中应还日期 < 当前日期）。
