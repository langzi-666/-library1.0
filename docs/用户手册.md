# 图书管理系统用户手册

## 1. 系统简介

### 1.1 系统概述
图书管理系统是一个功能完善的图书管理平台，支持图书信息管理、借阅管理、归还管理、统计报表等功能，为图书管理员和读者提供高效、便捷的服务。

### 1.2 系统功能
- **图书管理**：图书信息的增删改查、分类管理
- **用户管理**：用户注册、登录、信息管理
- **借阅管理**：图书借阅申请、续借、归还
- **统计报表**：数据统计、报表生成、可视化展示
- **系统设置**：借阅规则配置、系统参数设置

### 1.3 浏览器要求
- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+

## 2. 快速开始

### 2.1 访问系统
1. 在浏览器地址栏输入系统地址（如：`http://your-domain.com`）
2. 系统会自动跳转到登录页面

### 2.2 用户注册
1. 点击登录页面的"注册"按钮
2. 填写注册信息：
   - 用户名（必填，3-20个字符）
   - 密码（必填，至少8位）
   - 确认密码（必填，需与密码一致）
   - 邮箱（必填，有效的邮箱地址）
   - 手机号（必填，11位手机号）
   - 真实姓名（必填）
   - 验证码（必填，点击图片刷新）
3. 点击"注册"按钮
4. 注册成功后，系统会自动跳转到登录页面

### 2.3 用户登录
1. 在登录页面输入用户名和密码
2. 输入验证码（点击图片可刷新）
3. 点击"登录"按钮
4. 登录成功后，系统会根据用户角色跳转到相应页面

## 3. 普通用户操作指南

### 3.1 个人中心

#### 3.1.1 查看个人信息
1. 点击页面右上角的用户头像或用户名
2. 选择"个人中心"或"我的信息"
3. 查看个人信息，包括：
   - 用户ID
   - 用户名
   - 邮箱
   - 手机号
   - 真实姓名
   - 角色
   - 注册时间

#### 3.1.2 修改个人信息
1. 进入"个人中心"
2. 点击"编辑"按钮
3. 修改需要更新的信息（不能修改用户名和角色）
4. 点击"保存"按钮

#### 3.1.3 修改密码
1. 进入"个人中心"
2. 点击"修改密码"
3. 输入当前密码
4. 输入新密码（至少8位）
5. 确认新密码
6. 点击"保存"按钮

### 3.2 图书查询

#### 3.2.1 图书列表查询
1. 在首页或导航栏点击"图书管理"或"图书列表"
2. 系统显示图书列表，包括：
   - 图书编号
   - 书名
   - 作者
   - 出版社
   - ISBN
   - 分类
   - 库存状态
   - 操作按钮

#### 3.2.2 图书搜索
1. 在图书列表页面，使用搜索框输入关键词
2. 支持搜索条件：
   - 书名（支持模糊匹配）
   - 作者（支持模糊匹配）
   - ISBN（精确匹配）
   - 出版社（支持模糊匹配）
   - 分类（下拉选择）
   - 状态（下拉选择：在库/已借出/已下架）
3. 点击"搜索"按钮
4. 系统显示符合条件的图书列表

#### 3.2.3 查看图书详情
1. 在图书列表中点击图书名称或"详情"按钮
2. 查看图书详细信息，包括：
   - 图书基本信息（编号、书名、作者、出版社等）
   - 图书分类
   - 价格和库存
   - 图书描述
   - 封面图片
   - 借阅状态

### 3.3 图书借阅

#### 3.3.1 申请借阅
1. 在图书列表或详情页面，找到要借阅的图书
2. 确认图书状态为"在库"
3. 点击"借阅"按钮
4. 系统显示借阅规则（借阅期限、续借次数等）
5. 确认借阅信息，点击"确认借阅"
6. 系统提示借阅成功，显示：
   - 借阅记录编号
   - 应还日期
   - 借阅期限

#### 3.3.2 查看借阅记录
1. 点击导航栏"我的借阅"或"借阅记录"
2. 查看自己的借阅记录列表，包括：
   - 图书名称
   - 借阅日期
   - 应还日期
   - 归还日期
   - 借阅状态（借阅中/已归还/逾期）
   - 逾期天数（如有）
   - 逾期费用（如有）

#### 3.3.3 续借图书
1. 在"我的借阅"页面，找到需要续借的图书
2. 确认图书状态为"借阅中"且未逾期
3. 确认续借次数未达到上限
4. 点击"续借"按钮
5. 系统提示续借成功，显示新的应还日期

#### 3.3.4 归还图书
1. 在"我的借阅"页面，找到需要归还的图书
2. 确认图书状态为"借阅中"
3. 点击"归还"按钮
4. 确认归还信息
5. 系统提示归还成功

### 3.4 我的借阅

#### 3.4.1 查看借阅记录
1. 点击导航栏"我的借阅"
2. 查看借阅记录列表，支持筛选：
   - 按状态筛选（全部/借阅中/已归还/逾期）
   - 按借阅日期范围筛选
3. 点击记录可查看详细信息

#### 3.4.2 查看逾期记录
1. 在"我的借阅"页面，点击"逾期记录"标签
2. 查看逾期借阅记录，包括：
   - 逾期天数（红色显示）
   - 逾期费用（红色显示）
   - 应还日期
3. 及时归还逾期图书，避免产生更多费用

## 4. 图书管理员操作指南

### 4.1 图书管理

#### 4.1.1 添加图书
1. 点击导航栏"图书管理" → "添加图书"
2. 填写图书信息：
   - 书名（必填）
   - 作者（必填，多个作者用逗号分隔）
   - 出版社（必填）
   - 出版日期（必填）
   - ISBN（必填，需唯一）
   - 分类（必填，从下拉列表选择）
   - 价格（必填）
   - 库存数量（必填）
   - 图书描述（可选）
   - 封面图片（可选，支持上传）
3. 点击"保存"按钮
4. 系统提示添加成功，并显示图书编号

#### 4.1.2 编辑图书
1. 在图书列表中，找到要编辑的图书
2. 点击"编辑"按钮
3. 修改图书信息（图书编号不可修改）
4. 点击"保存"按钮
5. 系统提示更新成功

#### 4.1.3 删除图书
1. 在图书列表中，找到要删除的图书
2. 点击"删除"按钮
3. 系统提示确认删除
4. 确认删除后，系统检查：
   - 是否有未归还的借阅记录
   - 库存是否为零
5. 如果检查通过，系统删除图书并提示成功

#### 4.1.4 图书分类管理
1. 点击导航栏"图书管理" → "分类管理"
2. 查看分类树形结构（支持三级分类）
3. 添加分类：
   - 点击"添加分类"
   - 填写分类名称
   - 选择父分类（可选，不选择则为一级分类）
   - 设置排序顺序
   - 填写分类描述（可选）
   - 点击"保存"
4. 编辑分类：
   - 点击分类列表中的"编辑"按钮
   - 修改分类信息
   - 点击"保存"
5. 删除分类：
   - 点击"删除"按钮
   - 确认删除（系统会检查是否有子分类或图书使用该分类）

### 4.2 借阅管理

#### 4.2.1 处理借阅申请
1. 点击导航栏"借阅管理" → "借阅申请"
2. 查看待处理的借阅申请列表
3. 点击"处理"按钮
4. 确认借阅信息：
   - 用户信息
   - 图书信息
   - 借阅期限
5. 点击"批准"或"拒绝"按钮
6. 系统提示处理结果

#### 4.2.2 处理归还操作
1. 点击导航栏"借阅管理" → "归还管理"
2. 查看待归还的借阅记录
3. 选择归还方式：
   - 正常归还：图书完好
   - 损坏归还：图书有损坏，需填写损坏情况
   - 丢失处理：图书丢失，需填写丢失说明
4. 如为损坏或丢失，系统计算费用
5. 确认归还信息，点击"确认归还"
6. 系统提示归还成功

#### 4.2.3 查看借阅记录
1. 点击导航栏"借阅管理" → "借阅记录"
2. 使用查询条件筛选记录：
   - 用户ID或用户名
   - 图书名称或ISBN
   - 借阅状态
   - 借阅日期范围
3. 查看借阅记录列表，支持：
   - 查看详情
   - 导出Excel（管理员功能）

#### 4.2.4 查看逾期记录
1. 点击导航栏"借阅管理" → "逾期记录"
2. 查看逾期借阅记录列表
3. 支持按逾期天数排序
4. 支持导出逾期记录

### 4.3 统计报表

#### 4.3.1 查看统计概览
1. 点击导航栏"统计报表"
2. 查看统计概览卡片：
   - 总图书数
   - 总用户数
   - 总借阅次数
   - 当前借阅中
   - 逾期记录数

#### 4.3.2 查看详细统计
1. 在统计报表页面，点击"详细统计"
2. 查看各类统计信息：
   - 图书统计（按分类、按状态）
   - 用户统计（按角色、按状态）
   - 借阅统计（按时间、按图书、按用户）
3. 支持数据可视化图表展示

#### 4.3.3 查看热门图书
1. 在统计报表页面，点击"热门图书"
2. 查看借阅次数最多的图书排行
3. 支持按时间段筛选

#### 4.3.4 导出报表
1. 在统计报表页面，选择要导出的数据
2. 点击"导出Excel"按钮
3. 系统生成Excel文件并下载

## 5. 系统管理员操作指南

### 5.1 用户管理

#### 5.1.1 查看用户列表
1. 点击导航栏"用户管理"
2. 查看用户列表，支持：
   - 按用户名、姓名、邮箱、手机号搜索
   - 按角色筛选
   - 按状态筛选
   - 按注册日期范围筛选

#### 5.1.2 添加用户
1. 在用户管理页面，点击"添加用户"
2. 填写用户信息：
   - 用户名（必填，需唯一）
   - 密码（必填）
   - 邮箱（必填）
   - 手机号（必填）
   - 真实姓名（必填）
   - 角色（必填，从下拉列表选择）
3. 点击"保存"按钮

#### 5.1.3 编辑用户
1. 在用户列表中，找到要编辑的用户
2. 点击"编辑"按钮
3. 修改用户信息（包括角色）
4. 点击"保存"按钮

#### 5.1.4 删除用户
1. 在用户列表中，找到要删除的用户
2. 点击"删除"按钮
3. 系统检查用户是否有未归还的图书
4. 确认删除后，系统删除用户

#### 5.1.5 锁定/解锁用户
1. 在用户列表中，找到要操作的用户
2. 点击"锁定"或"解锁"按钮
3. 系统提示操作成功

#### 5.1.6 重置用户密码
1. 在用户列表中，找到要重置密码的用户
2. 点击"重置密码"按钮
3. 输入新密码
4. 确认新密码
5. 点击"保存"按钮

### 5.2 系统设置

#### 5.2.1 借阅规则配置
1. 点击导航栏"系统设置" → "借阅规则"
2. 配置借阅规则：
   - 最大借阅数量（每个用户最多可借阅的图书数）
   - 借阅期限（天数）
   - 续借次数（最多可续借的次数）
   - 续借期限（每次续借的天数）
   - 逾期费用（每天的费用）
3. 点击"保存"按钮

#### 5.2.2 系统参数配置
1. 点击导航栏"系统设置" → "系统参数"
2. 配置系统参数：
   - 系统名称
   - 系统Logo
   - 系统公告
   - 联系方式
3. 点击"保存"按钮

#### 5.2.3 数据备份
1. 点击导航栏"系统设置" → "数据备份"
2. 查看备份列表
3. 创建备份：
   - 点击"创建备份"按钮
   - 输入备份名称（可选）
   - 选择备份类型（完整备份/增量备份）
   - 点击"确认"
4. 恢复备份：
   - 在备份列表中，找到要恢复的备份
   - 点击"恢复"按钮
   - 确认恢复操作

### 5.3 操作日志

#### 5.3.1 查看操作日志
1. 点击导航栏"系统设置" → "操作日志"
2. 查看操作日志列表，支持：
   - 按用户筛选
   - 按操作类型筛选
   - 按时间范围筛选
   - 按操作结果筛选
3. 查看日志详情，包括：
   - 用户信息
   - 操作类型
   - 操作描述
   - IP地址
   - 操作时间
   - 操作结果

## 6. 常见问题

### 6.1 登录问题

**Q: 忘记密码怎么办？**
A: 请联系系统管理员重置密码。

**Q: 登录时提示"验证码错误"怎么办？**
A: 点击验证码图片刷新验证码，重新输入。

**Q: 账户被锁定怎么办？**
A: 请联系系统管理员解锁账户。

### 6.2 借阅问题

**Q: 为什么不能借阅图书？**
A: 可能的原因：
- 已达到最大借阅数量
- 图书库存不足
- 有逾期未归还的图书
- 账户状态异常

**Q: 可以续借几次？**
A: 根据系统配置的借阅规则，通常可以续借1-2次，具体以系统提示为准。

**Q: 逾期费用如何计算？**
A: 逾期费用 = 逾期天数 × 每天费用，具体费用标准以系统配置为准。

### 6.3 图书问题

**Q: 如何搜索图书？**
A: 在图书列表页面，使用搜索框输入关键词（书名、作者、ISBN等），点击"搜索"按钮。

**Q: 为什么看不到某些图书？**
A: 可能的原因：
- 图书已被下架
- 图书状态为"已损坏"或"已丢失"
- 权限不足

### 6.4 其他问题

**Q: 如何修改个人信息？**
A: 点击右上角用户头像，选择"个人中心"，点击"编辑"按钮修改信息。

**Q: 如何查看我的借阅记录？**
A: 点击导航栏"我的借阅"，即可查看所有借阅记录。

**Q: 系统使用过程中遇到问题怎么办？**
A: 可以：
1. 查看本用户手册
2. 联系系统管理员
3. 查看系统帮助文档

## 7. 注意事项

### 7.1 安全提示
- 请妥善保管账号密码，不要泄露给他人
- 定期修改密码，建议使用强密码
- 使用完毕后及时退出登录
- 不要在公共电脑上保存登录信息

### 7.2 操作提示
- 借阅图书前，请确认图书状态和库存
- 归还图书时，请确认图书完好
- 如有图书损坏或丢失，请及时告知管理员
- 逾期图书请及时归还，避免产生额外费用

### 7.3 数据说明
- 图书信息以系统显示为准
- 借阅记录以系统记录为准
- 如有疑问，请联系管理员核实
