**业务规则验证：**
1. **借阅规则**
   - 检查图书库存是否充足
   - 检查用户是否已借阅该图书且未归还（避免重复借阅）
   - 检查用户当前借阅数量是否超过限制（普通用户最多同时借阅5本）
   - 检查用户是否有逾期未还的图书（如有，需先归还才能借阅新书）
   - 检查用户账户状态是否正常（锁定或注销账户不能借阅）
   - 计算应还日期：借阅日期 + 借阅期限（默认30天）

2. **归还规则**
   - 检查借阅记录是否存在且未归还
   - 计算是否逾期及逾期天数
   - 计算逾期费用（每天1元）
   - 根据图书状态更新库存（正常/损坏/丢失）
   - 图书丢失时不增加库存，且减少总库存

3. **续借规则**
   - 只能在应还日期前7天内申请续借
   - 每本图书最多续借1次
   - 已逾期的图书不能续借
   - 续借期限为30天

**借阅规则配置：**
- `MAX_BORROW_COUNT = 5` - 普通用户最多同时借阅5本
- `BORROW_DAYS = 30` - 借阅期限30天
- `MAX_RENEW_COUNT = 1` - 最多续借1次
- `OVERDUE_FEE_PER_DAY = 1.00` - 每天逾期费用1元

## 业务规则

### 借阅规则
1. **借阅限制**
   - 普通用户最多同时借阅5本图书
   - 同一图书最多借阅3本
   - 不能重复借阅未归还的同一图书
   - 有逾期未还图书时不能借阅新书

2. **借阅期限**
   - 默认借阅期限30天
   - 续借期限30天
   - 最多续借1次

3. **用户状态检查**
   - 锁定账户不能借阅
   - 已注销账户不能借阅

### 归还规则
1. **归还处理**
   - 正常归还：增加可用库存
   - 损坏归还：增加可用库存，但图书状态标记为"损坏"
   - 丢失归还：不增加库存，且减少总库存

2. **逾期计算**
   - 逾期天数 = 归还日期 - 应还日期
   - 逾期费用 = 逾期天数 × 1元/天

### 续借规则
1. **续借条件**
   - 只能在应还日期前7天内申请续借
   - 已逾期的图书不能续借
   - 最多续借1次

2. **续借处理**
   - 更新应还日期 = 原应还日期 + 续借天数
   - 续借次数 + 1

## 遇到的问题及解决方案

### 问题1：借阅记录关联查询
**问题描述**：需要查询借阅记录时同时获取图书和用户信息
**解决方案**：使用MyBatis XML映射文件，通过LEFT JOIN关联查询user表和book表

### 问题2：借阅权限验证
**问题描述**：需要验证用户是否可以借阅（库存、借阅数量、逾期等）
**解决方案**：在BorrowServiceImpl中实现checkBorrowPermission()方法，集中验证所有借阅条件

### 问题3：逾期状态更新
**问题描述**：需要定期更新借阅记录的逾期状态
**解决方案**：实现updateOverdueStatus()方法，查询所有借阅中且已逾期的记录，更新状态和逾期信息

### 问题4：归还时图书状态处理
**问题描述**：需要根据归还时的图书状态（正常/损坏/丢失）进行不同的库存处理
**解决方案**：
- 正常：增加可用库存
- 损坏：增加可用库存，更新图书状态为"损坏"
- 丢失：不增加库存，减少总库存

### 问题5：前端借阅申请流程
**问题描述**：需要先查询图书信息，确认后再提交借阅申请
**解决方案**：在BorrowApply.vue中实现两步流程：1. 查询图书信息 2. 确认后提交借阅申请
