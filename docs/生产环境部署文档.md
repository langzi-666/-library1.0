# 图书管理系统生产环境部署文档

## 1. 部署概述

### 1.1 系统架构
- **后端**：Spring Boot 2.7.18 + MyBatis Plus
- **前端**：Vue 3 + Element Plus
- **数据库**：MySQL 8.0+
- **Web服务器**：Nginx（前端静态资源）
- **应用服务器**：内嵌Tomcat（Spring Boot）

### 1.2 部署环境要求

#### 硬件要求
- **CPU**：4核或更高
- **内存**：8GB或更高（推荐16GB）
- **磁盘**：50GB或更高（SSD推荐）
- **网络**：100Mbps或更高

#### 软件要求
- **操作系统**：Linux（CentOS 7+ / Ubuntu 20.04+）或 Windows Server
- **JDK**：Java 17或更高版本
- **MySQL**：MySQL 8.0或更高版本
- **Nginx**：1.18或更高版本（可选，用于前端静态资源）
- **Maven**：3.6或更高版本（用于构建）

## 3. 数据库部署

### 3.1 创建数据库

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE library1.4 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建数据库用户（可选，推荐）
CREATE USER 'library_user'@'localhost' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON library1.4.* TO 'library_user'@'localhost';
FLUSH PRIVILEGES;

-- 退出
EXIT;
```

### 3.2 初始化数据库

```bash
# 执行数据库初始化脚本
mysql -u library_user -p library1.4 < database/init.sql

# 执行数据库性能优化脚本（可选）
mysql -u library_user -p library1.4 < database/performance_optimization.sql
```

### 3.3 数据库配置优化

编辑MySQL配置文件 `/etc/mysql/my.cnf` 或 `/etc/my.cnf`：

```ini
[mysqld]
# 字符集
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci

# 连接数
max_connections=200
max_connect_errors=10

# 缓冲区
innodb_buffer_pool_size=2G
innodb_log_file_size=512M

# 慢查询日志
slow_query_log=1
slow_query_log_file=/var/log/mysql/slow-query.log
long_query_time=2

# 二进制日志（用于备份）
log-bin=mysql-bin
binlog_format=ROW
expire_logs_days=7
```

重启MySQL服务：
```bash
systemctl restart mysql
# 或
systemctl restart mysqld
```

## 4. 后端部署

### 4.1 构建后端项目

```bash
# 进入后端目录
cd backend

# 使用Maven构建项目
mvn clean package -DskipTests

# 构建完成后，jar包在 target/ 目录下
# library-management-system-1.0.0.jar
```

### 4.2 配置生产环境

编辑 `src/main/resources/application-prod.yml`：

```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/library1.4?useUnicode=true&characterEncoding=utf8&useSSL=true&serverTimezone=Asia/Shanghai
    username: library_user
    password: your_strong_password
    
    druid:
      # 生产环境连接池配置
      initial-size: 10
      min-idle: 10
      max-active: 50
      max-wait: 60000
      
      # 监控配置（生产环境建议关闭或限制访问）
      stat-view-servlet:
        enabled: true
        url-pattern: /druid/*
        login-username: admin
        login-password: change_this_password
        
# 日志配置
logging:
  level:
    root: INFO
    com.library: INFO
  file:
    name: /opt/library-management/logs/application.log
    max-size: 100MB
    max-history: 30
```

### 4.3 部署后端应用

```bash
# 复制jar包到部署目录
cp target/library-management-system-1.0.0.jar /opt/library-management/backend/

# 复制配置文件
cp src/main/resources/application-prod.yml /opt/library-management/backend/

# 创建启动脚本
cat > /opt/library-management/backend/start.sh << 'EOF'
#!/bin/bash
cd /opt/library-management/backend
nohup java -jar \
  -Xms512m \
  -Xmx2048m \
  -XX:+UseG1GC \
  -Dspring.profiles.active=prod \
  library-management-system-1.0.0.jar \
  > /opt/library-management/logs/backend.log 2>&1 &
echo $! > /opt/library-management/backend/app.pid
echo "应用已启动，PID: $(cat /opt/library-management/backend/app.pid)"
EOF

chmod +x /opt/library-management/backend/start.sh

# 创建停止脚本
cat > /opt/library-management/backend/stop.sh << 'EOF'
#!/bin/bash
if [ -f /opt/library-management/backend/app.pid ]; then
    PID=$(cat /opt/library-management/backend/app.pid)
    kill $PID
    rm /opt/library-management/backend/app.pid
    echo "应用已停止"
else
    echo "应用未运行"
fi
EOF

chmod +x /opt/library-management/backend/stop.sh

# 创建重启脚本
cat > /opt/library-management/backend/restart.sh << 'EOF'
#!/bin/bash
/opt/library-management/backend/stop.sh
sleep 2
/opt/library-management/backend/start.sh
EOF

chmod +x /opt/library-management/backend/restart.sh
```

### 4.4 配置系统服务（Systemd）

```bash
# 创建systemd服务文件
cat > /etc/systemd/system/library-backend.service << 'EOF'
[Unit]
Description=Library Management System Backend
After=network.target mysql.service

[Service]
Type=simple
User=library
WorkingDirectory=/opt/library-management/backend
ExecStart=/usr/bin/java -jar \
  -Xms512m \
  -Xmx2048m \
  -XX:+UseG1GC \
  -Dspring.profiles.active=prod \
  library-management-system-1.0.0.jar
ExecStop=/bin/kill -15 $MAINPID
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF

# 重新加载systemd配置
systemctl daemon-reload

# 设置开机自启
systemctl enable library-backend

# 启动服务
systemctl start library-backend

# 查看服务状态
systemctl status library-backend
```

## 5. 前端部署

### 5.1 构建前端项目

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 构建生产版本
npm run build

# 构建完成后，dist/ 目录包含静态文件
```

### 5.2 配置Nginx

```bash
# 安装Nginx（如果未安装）
# CentOS/RHEL
yum install nginx
# Ubuntu/Debian
apt-get install nginx

# 创建Nginx配置
cat > /etc/nginx/conf.d/library.conf << 'EOF'
server {
    listen 80;
    server_name your_domain.com;  # 替换为实际域名或IP

    # 前端静态文件
    root /opt/library-management/frontend/dist;
    index index.html;

    # 前端路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # 日志
    access_log /var/log/nginx/library-access.log;
    error_log /var/log/nginx/library-error.log;
}
EOF

# 测试Nginx配置
nginx -t

# 启动Nginx
systemctl start nginx
systemctl enable nginx

# 重新加载配置
systemctl reload nginx
```

### 5.3 部署前端文件

## 6. 防火墙配置

### 6.1 Linux防火墙（firewalld）

```bash
# 开放HTTP端口
firewall-cmd --permanent --add-service=http
# 开放HTTPS端口
firewall-cmd --permanent --add-service=https
# 开放后端API端口（如果需要外部访问）
firewall-cmd --permanent --add-port=8080/tcp
# 重新加载防火墙
firewall-cmd --reload
```

### 6.2 Linux防火墙（ufw）

```bash
# 开放HTTP端口
ufw allow 80/tcp
# 开放HTTPS端口
ufw allow 443/tcp
# 开放后端API端口（如果需要外部访问）
ufw allow 8080/tcp
# 启用防火墙
ufw enable
```

## 8. 备份策略

### 8.1 数据库备份

```bash
# 创建备份脚本
cat > /opt/library-management/backup/backup-db.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/opt/library-management/backup"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/library_db_$DATE.sql"

# 备份数据库
mysqldump -u library_user -p'your_password' library1.4 > $BACKUP_FILE

# 压缩备份文件
gzip $BACKUP_FILE

# 删除30天前的备份
find $BACKUP_DIR -name "library_db_*.sql.gz" -mtime +30 -delete

echo "数据库备份完成: $BACKUP_FILE.gz"
EOF

chmod +x /opt/library-management/backup/backup-db.sh

# 添加到crontab（每天凌晨2点备份）
crontab -e
# 添加以下行：
# 0 2 * * * /opt/library-management/backup/backup-db.sh
```

### 8.2 应用备份

```bash
# 创建应用备份脚本
cat > /opt/library-management/backup/backup-app.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/opt/library-management/backup"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/library_app_$DATE.tar.gz"

# 备份应用和配置
tar -czf $BACKUP_FILE \
    /opt/library-management/backend \
    /opt/library-management/frontend \
    /opt/library-management/logs

# 删除30天前的备份
find $BACKUP_DIR -name "library_app_*.tar.gz" -mtime +30 -delete

echo "应用备份完成: $BACKUP_FILE"
EOF

chmod +x /opt/library-management/backup/backup-app.sh
```

## 11. 回滚方案

### 11.1 应用回滚

```bash
# 停止当前版本
/opt/library-management/backend/stop.sh

# 恢复备份版本
cp /opt/library-management/backup/library_app_*.tar.gz /tmp/
cd /tmp
tar -xzf library_app_*.tar.gz
cp -r opt/library-management/backend/* /opt/library-management/backend/

# 启动旧版本
/opt/library-management/backend/start.sh
```

### 11.2 数据库回滚

```bash
# 恢复数据库备份
mysql -u library_user -p library1.4 < /opt/library-management/backup/library_db_*.sql
```

## 12. 安全建议

1. **密码安全**
   - 使用强密码
   - 定期更换密码
   - 不要在代码中硬编码密码

2. **网络安全**
   - 使用HTTPS
   - 限制Druid监控访问（IP白名单）
   - 关闭不必要的端口

3. **系统安全**
   - 定期更新系统和软件
   - 配置防火墙规则
   - 启用日志审计

4. **数据安全**
   - 定期备份数据库
   - 加密敏感数据
   - 限制数据库访问权限
