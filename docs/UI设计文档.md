# UI设计文档

## 1. 设计概述

### 1.1 设计目标
- 提供现代化、美观的用户界面
- 优化用户体验，提升操作效率
- 确保界面在不同设备上的良好显示
- 保持设计风格的一致性

### 1.2 设计原则
- **简洁性**：界面简洁明了，避免冗余元素
- **一致性**：保持设计风格和交互模式的一致性
- **可用性**：确保用户能够轻松理解和使用系统
- **响应式**：适配不同屏幕尺寸的设备

## 2. 设计规范

### 2.1 色彩系统

#### 主题色彩
```css
--primary-color: #409EFF;      /* 主色调 - 蓝色 */
--success-color: #67C23A;       /* 成功色 - 绿色 */
--warning-color: #E6A23C;       /* 警告色 - 橙色 */
--danger-color: #F56C6C;        /* 危险色 - 红色 */
--info-color: #909399;          /* 信息色 - 灰色 */
```

#### 渐变色彩
```css
--gradient-primary: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
--gradient-secondary: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
--gradient-success: linear-gradient(135deg, #4facfe 0%, #00f2fe 100%);
```

#### 文字色彩
- **主要文字**：`#303133` - 用于标题和重要内容
- **常规文字**：`#606266` - 用于正文内容
- **次要文字**：`#909399` - 用于辅助信息和说明
- **占位文字**：`#C0C4CC` - 用于输入框占位符

#### 背景色彩
- **主背景**：`#f5f7fa` - 页面主背景色
- **卡片背景**：`#ffffff` - 卡片和面板背景
- **次要背景**：`#fafafa` - 搜索栏等次要区域

### 2.2 阴影系统

```css
--shadow-sm: 0 2px 4px rgba(0, 0, 0, 0.08);      /* 小阴影 */
--shadow-md: 0 4px 12px rgba(0, 0, 0, 0.1);      /* 中等阴影 */
--shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.12);     /* 大阴影 */
--shadow-hover: 0 12px 32px rgba(0, 0, 0, 0.15);  /* 悬停阴影 */
```

### 2.3 圆角系统

```css
--radius-sm: 4px;   /* 小圆角 - 输入框、小按钮 */
--radius-md: 8px;   /* 中等圆角 - 卡片、按钮 */
--radius-lg: 12px;  /* 大圆角 - 大卡片 */
--radius-xl: 16px;  /* 超大圆角 - 登录框等 */
```

### 2.4 间距系统

统一使用8px的倍数作为间距单位：
```css
--spacing-xs: 4px;   /* 超小间距 */
--spacing-sm: 8px;   /* 小间距 */
--spacing-md: 16px; /* 中等间距 */
--spacing-lg: 24px; /* 大间距 */
--spacing-xl: 32px; /* 超大间距 */
```

### 2.5 字体系统

#### 字体族
- **中文**：`'Microsoft YaHei', '微软雅黑', 'PingFang SC', 'Hiragino Sans GB'`
- **英文**：`Arial, sans-serif`
- **等宽字体**：`'Courier New', monospace`

#### 字号
- **标题**：24px - 28px（页面主标题）
- **副标题**：18px - 20px（区域标题）
- **正文**：14px - 16px（主要内容）
- **辅助文字**：12px - 14px（说明、提示）
- **小字**：10px - 12px（次要信息）

#### 字重
- **粗体**：600 - 700（标题、重要内容）
- **中等**：500（副标题、标签）
- **常规**：400（正文内容）

### 2.6 动画效果

#### 过渡时间
- **快速**：0.2s - 简单交互
- **标准**：0.3s - 常规过渡
- **慢速**：0.5s - 复杂动画

#### 缓动函数
- **ease-out**：进入动画
- **ease-in**：退出动画
- **ease**：通用过渡

## 3. 组件设计

### 3.1 按钮

#### 主要按钮
- 使用渐变背景色（`var(--gradient-primary)`）
- 圆角：8px
- 悬停效果：上移2px，增强阴影
- 点击效果：恢复原位

#### 次要按钮
- 白色背景，主色边框
- 悬停时背景色变化

#### 危险按钮
- 红色背景
- 用于删除等危险操作

### 3.2 输入框

- 圆角：8px
- 悬停时阴影增强
- 聚焦时显示蓝色边框光晕
- 占位符文字颜色：`#C0C4CC`

### 3.3 卡片

- 圆角：12px
- 白色背景
- 小阴影（`var(--shadow-sm)`）
- 悬停时阴影增强，轻微上移
- 内部间距：20px - 24px

### 3.4 表格

- 表头背景：`#fafafa`
- 表头文字：加粗，颜色 `#606266`
- 行悬停：背景色变为 `#f5f7fa`
- 单元格内边距：16px 0

### 3.5 菜单

- 菜单项圆角：8px
- 悬停效果：背景色变化，向右移动4px
- 激活状态：渐变背景，白色文字
- 子菜单项：左侧缩进50px

## 4. 页面设计

### 4.1 登录页面

#### 设计特点
- 全屏渐变背景（紫蓝色渐变）
- 动态点状背景图案
- 居中登录框，毛玻璃效果
- 入场动画：从下方滑入

#### 布局
- 登录框宽度：420px（桌面端）
- 登录框圆角：16px
- 内边距：50px 40px
- 阴影：大阴影增强层次感

#### 交互
- 输入框聚焦：蓝色光晕
- 按钮悬停：上移并增强阴影
- 响应式：移动端宽度95%，内边距减小

### 4.2 注册页面

#### 设计特点
- 与登录页面一致的背景设计
- 表单宽度：700px（桌面端）
- 支持滚动（最大高度90vh）
- 美化滚动条

#### 响应式
- 移动端：宽度95%，标签宽度80px
- 表单字段垂直排列

### 4.3 主布局

#### 顶部导航栏
- 渐变背景（紫蓝色）
- 高度：60px
- 左侧：系统标题
- 右侧：用户信息和下拉菜单
- 底部装饰线：半透明渐变

#### 侧边栏
- 宽度：200px（展开）/ 64px（收起）
- 白色背景
- 右侧阴影
- 菜单项圆角和悬停效果

#### 主内容区
- 背景色：`#f5f7fa`
- 内边距：24px
- 路由过渡动画：淡入淡出 + 水平移动

### 4.4 首页（Dashboard）

#### 欢迎卡片
- 渐变文字标题
- 大图标装饰（透明度0.2）
- 悬停时图标放大

#### 统计卡片
- 图标区域：64px × 64px，圆角12px
- 悬停效果：卡片上移，图标旋转放大
- 数值颜色变化为主色调

#### 快捷操作
- 卡片式布局
- 悬停时有光效扫过
- 图标和文字颜色变化

### 4.5 列表页面

#### 搜索栏
- 浅灰背景（`#fafafa`）
- 圆角：8px
- 内边距：20px

#### 表格
- 圆角：8px
- 表头样式优化
- 行悬停效果
- 操作按钮样式统一

#### 分页
- 右对齐
- 底部间距：24px

## 5. 响应式设计

### 5.1 断点设置

```css
/* 移动端 */
@media (max-width: 480px) { }

/* 平板 */
@media (max-width: 768px) { }

/* 小桌面 */
@media (max-width: 1200px) { }
```

### 5.2 移动端适配

#### 布局调整
- 侧边栏：绝对定位，覆盖在主内容上
- 表格：字体缩小，列宽自适应
- 按钮：移动端全宽显示
- 卡片：减少内边距

#### 交互优化
- 增大点击区域
- 简化操作流程
- 减少动画效果（性能优化）

### 5.3 平板适配

- 保持主要布局结构
- 调整间距和字体大小
- 优化表格显示（可能横向滚动）

## 6. 动画和过渡

### 6.1 页面过渡

#### 路由切换
- 淡入淡出：0.3s
- 水平移动：20px
- 模式：out-in（先出后进）

### 6.2 元素动画

#### 入场动画
- 页面加载：从下方滑入（fadeIn）
- 卡片出现：淡入 + 上移

#### 悬停动画
- 按钮：上移2px + 阴影增强
- 卡片：上移4-6px + 阴影增强
- 图标：放大 + 旋转

#### 点击动画
- 按钮：恢复原位
- 反馈：轻微缩放

### 6.3 加载状态

- 使用Element Plus的loading组件
- 骨架屏（可选）
- 加载动画：旋转或脉冲

## 7. 交互反馈

### 7.1 操作反馈

#### 成功提示
- 绿色提示框
- 显示时间：2-3秒
- 位置：顶部居中

#### 错误提示
- 红色提示框
- 显示时间：3-4秒
- 位置：顶部居中

#### 警告提示
- 橙色提示框
- 用于确认对话框

### 7.2 表单验证

- 实时验证：输入时显示错误
- 错误提示：输入框下方红色文字
- 成功状态：绿色边框（可选）

### 7.3 确认对话框

- 危险操作：红色警告图标
- 普通操作：蓝色信息图标
- 内容：明确说明操作后果

## 8. 无障碍设计

### 8.1 键盘导航

- Tab键：顺序导航
- Enter键：触发主要操作
- Esc键：关闭对话框

### 8.2 语义化

- 使用语义化HTML标签
- ARIA标签（可选）
- 合理的标题层级

### 8.3 色彩对比度

- 文字与背景对比度：≥4.5:1
- 大文字对比度：≥3:1
- 重要元素对比度：≥7:1

## 9. 性能优化

### 9.1 动画性能

- 使用transform和opacity进行动画
- 避免使用width、height等属性
- 使用will-change提示浏览器

### 9.2 图片优化

- 使用适当的图片格式
- 懒加载（如需要）
- 响应式图片

### 9.3 代码优化

- CSS变量减少重复代码
- 使用scoped样式避免冲突
- 合理使用深度选择器

## 10. 设计规范实施

### 10.1 全局样式

所有样式定义在`App.vue`中：
- CSS变量定义
- 全局动画
- 滚动条美化
- 通用工具类

### 10.2 组件样式

- 使用scoped样式
- 深度选择器覆盖Element Plus样式
- 保持样式模块化

### 10.3 响应式实现

- 移动优先设计
- 使用媒体查询
- 弹性布局（Flexbox/Grid）
