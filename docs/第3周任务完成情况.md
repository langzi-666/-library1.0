**核心实现：**
- `BookService.updateStock()` - 更新库存
- `BookService.increaseStock()` - 增加库存
- `BookService.decreaseStock()` - 减少库存
- `BookService.updateAvailableStock()` - 更新可用库存

**库存管理规则：**
- 总库存（stock）：图书的总数量
- 可用库存（available_stock）：可以借出的数量（总库存 - 已借出数量）
- 增加库存时，同时增加可用库存
- 减少库存时，同时减少可用库存（但不能小于0）
- 更新库存时，如果可用库存大于新库存，自动调整可用库存

## 业务规则

### 图书管理规则
1. **图书ID生成规则**
   - 格式：BK + YYYYMMDD + 4位流水号
   - 例如：BK20241201001

2. **ISBN唯一性**
   - ISBN必须唯一
   - 创建和更新时验证ISBN是否重复

3. **分类关联**
   - 图书必须关联分类
   - 创建和更新时验证分类是否存在

4. **库存管理**
   - 库存不能为负数
   - 可用库存不能大于总库存
   - 可用库存 = 总库存 - 已借出数量

5. **图书状态**
   - 在库：图书可借阅
   - 已借出：所有图书都被借出
   - 已下架：图书不再对外借阅
   - 损坏：图书已损坏

### 分类管理规则
1. **分类级别**
   - 支持三级分类（level: 1/2/3）
   - 一级分类的parentId为0
   - 子分类的level = 父分类level + 1

2. **分类删除规则**
   - 有子分类的分类不能删除
   - 有关联图书的分类不能删除

3. **分类树形结构**
   - 支持树形结构展示
   - 按sortOrder排序

## 遇到的问题及解决方案

### 问题1：分类树形结构构建
**问题描述**：需要将平铺的分类列表构建成树形结构
**解决方案**：实现递归方法buildTree()，遍历所有分类，根据parentId构建父子关系

### 问题2：图书ID生成
**问题描述**：需要生成唯一且有序的图书ID
**解决方案**：实现BookIdGenerator工具类，格式：BK+年月日+4位流水号，查询当天最大流水号后递增

### 问题3：多条件查询
**问题描述**：需要支持多条件动态查询
**解决方案**：使用MyBatis Plus的LambdaQueryWrapper，根据DTO中的条件动态构建查询语句

### 问题4：库存管理
**问题描述**：需要区分总库存和可用库存
**解决方案**：
- 总库存（stock）：图书的总数量
- 可用库存（available_stock）：可以借出的数量
- 增加/减少库存时同步更新可用库存
- 借阅和归还时更新可用库存（后续借阅模块实现）
