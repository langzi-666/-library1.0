# 第8周核心功能测试计划和测试用例

## 测试概述

### 测试目标
对图书管理系统的核心功能进行全面测试，包括功能测试、业务流程测试、Bug修复和代码优化。

### 测试范围
- 用户管理模块
- 图书管理模块
- 借阅管理模块
- 归还管理模块
- 借阅记录查询模块
- 统计报表模块
- 业务流程完整性

### 测试环境
- **后端**：Spring Boot 2.7.18 + MySQL 8.0
- **前端**：Vue 3 + Element Plus
- **测试工具**：Postman、浏览器开发者工具
