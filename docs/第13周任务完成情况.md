### 使用说明

#### 部署系统
```bash
# 生产环境部署
sudo ./scripts/deploy.sh prod

# 开发环境部署
sudo ./scripts/deploy.sh dev
```

#### 备份系统
```bash
# 完整备份（数据库+应用）
./scripts/backup.sh all

# 仅备份数据库
./scripts/backup.sh db

# 仅备份应用
./scripts/backup.sh app
```
